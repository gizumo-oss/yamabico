# yamabico

Gizumo音声コンテンツ配信サービスプラットフォーム

## Getting Started
> [!NOTE]
> 事前に以下を済ませてください。
> - GitHubのSSH接続設定
> - 自身のモバイル端末で[Expo Go](https://expo.dev/go)をインストール
> - [Volta](https://volta.sh/)をインストール(Homebrewでもインストール可)

1. 任意のディレクトリで以下を実行して環境を構築
  ```sh
  git@github.com:gizumo-oss/yamabico.git && cd yamabico && make setup
  ```
2. ローカルサーバー起動
  ```sh
  make dev
  ```
